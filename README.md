# atividade-pagina-interativa-dom
Atividade: Página Interativa com DOM

Objetivo :
- Desenvolver uma página web interativa que possua modo claro e modo escuro, permitindo alterar automaticamente as cores da interface (fundo e texto) conforme o modo selecionado. 
- A aplicação também deve permitir a identificação do usuário por meio de um campo de entrada de nome. 

O projeto deve utilizar os seguintes conceitos: 
- DOM (Document Object Model) 
- Manipulação de elementos HTML com JavaScript 
- Eventos do DOM 
- Requisitos da Aplicação 

1. Campo de Entrada 
A página deve conter: 
- Um campo de texto para o usuário digitar seu nome 
- Um botão para enviar o valor digitado
  
2. Exibição de Mensagem 
- Ao clicar no botão, deve ser exibida uma mensagem personalizada na tela contendo o nome informado pelo usuário
  
3. Manipulação de Estilo (Modo Claro/Escuro) 
A aplicação deve possuir: 
- Um botão para alternar entre modo claro e modo escuro 
- Ao alterar o modo, a página deve modificar: 
  A cor de fundo 
  A cor do texto
  
4. Uso de Eventos 
- A aplicação deve utilizar eventos do DOM, como: Evento de clique (click)
